Plateforme Ousagi

Cinq étapes pour passer de la connexion au premier training.

  1. Se connecter

    Saisissez l’identifiant (login) fourni par les responsables.

  2. Choisir le projet

    Sélectionnez le projet souhaité.

  3. Choisir une catégorie

    Choisissez une catégorie parmi les suivantes :

    Naturel Auto Référentiel

  4. Trouver le training

    Utilisez l’onglet de recherche pour localiser le training.

  5. Démarrer

    Cliquez sur Start pour démarrer le training.

Pour le détail de la plateforme, ouvrez la consigne de la plateforme.

Les trois types de labélisation

Chaque catégorie de la plateforme a sa propre consigne. Lisez celle qui correspond à votre training avant de commencer.

Natural

Labélisation manuelle : vous créez chaque crop vous-même. Suivez attentivement les consignes propres à ce type.

Consigne Natural
Auto

Vérification des crops d’une frame prédéfinie : repérez les oublis et les crops mal ajustés, puis corrigez-les si nécessaire.

Consigne Auto
Référentiel

Un seul crop par facing : chaque facing présent dans une vidéo est croppé une seule fois.

Consigne Référentiel

Méthodologie de labélisation

Suivez les étapes dans l’ordre. Chaque méthode a aussi sa fiche détaillée.

Frame Naturel

Ouvrir la méthodologie

  1. Sélectionnez une frame correcte (voir la consigne FN).

  2. Connaissez toutes les marques.

  3. Cliquez sur les groupes ainsi que sur l’onglet SAME EAN pour afficher toutes les classes.

  4. Faites le balayage en serpent pour éviter tout oubli.

  5. Utilisez la nomenclature de la classe pour bien labéliser : « Quantité ; EAN ; sns … ».

  6. Affichez la classe en grand format pour éviter les confusions.

  7. Labélisez.

Frame Auto

Ouvrir la méthodologie

  1. Sélectionnez une frame correcte (voir la consigne FN).

  2. Connaissez toutes les marques.

  3. Cliquez sur les groupes ainsi que sur l’onglet SAME EAN pour afficher toutes les classes.

  4. Après être entré dans un groupe, appuyez sur X ou W pour enlever le curseur sur « Assignate ».

  5. Faites le balayage en serpent pour éviter tout oubli.

  6. Utilisez la nomenclature de la classe pour bien labéliser : « Quantité ; EAN ; sns … ».

  7. Affichez la classe en grand format pour éviter les confusions.

  8. Modifiez, labélisez ou effacez des crops si nécessaire.

Création d’une nouvelle classe

Ouvrir la méthodologie

Créez une nouvelle classe si et seulement si la marque et la saveur sont les mêmes.

  1. Appuyez sur l’option Create New classe.

  2. Sélectionnez le visuel.

  3. Créez la classe en suivant l’instruction.

  4. Rattachez bien la classe à l’EAN cible.

  5. Sélectionnez bien les listes déroulantes (confirmez au responsable en cas de doute).

  6. Si le produit ne peut pas être créé en nouvelle classe :

    • Quantité différente, même marque : créez-le en 8888 et mettez-le dans CAA.
    • Saveur différente, même marque : créez-le en 8888 et mettez-le dans CAA.
